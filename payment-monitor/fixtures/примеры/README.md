# Примеры выписок

Набор вымышленных выписок в разных «банковских» стилях. Нужен, чтобы проверить,
что программа сама распознаёт колонки и статусы, а не работает только с одним форматом.

Все реквизиты, ИНН, счета и суммы — **вымышленные**.

## Файлы

| Файл | Что имитирует | Чему учит |
|---|---|---|
| `01_классическая_выписка.xlsx` | «Сбербанк-стиль»: `Дата операции`, `Номер документа`, `Контрагент`, `Назначение платежа`, `Сумма`, `Валюта`, `Статус` | базовый случай; есть «шапка» банка и служебные строки «Итого» / «Остаток» (их программа пропускает) |
| `02_статусы_латиницей.xlsx` | «Т-Банк-стиль»: `Дата`, `Номер`, `Получатель`, `Описание`, `Сумма`, `Статус` | статусы латиницей (`SUCCESS`, `PENDING`, `FAILED`, `CANCELED`, `REFUND`), нет колонки валюты, **второй лист** (`Информация`) не мешает разбору |
| `03_состояние_документа.xlsx` | «Альфа-Банк-стиль»: `Дата проводки`, `№ документа`, `Плательщик`, `Назначение платежа`, `Сумма в валюте счёта`, `Код валюты`, `Состояние документа` | статус в колонке «Состояние документа»; сумма и валюта — в **разных** колонках, хотя в названии суммы есть слово «валюте» |
| `04_сокращённая_без_валюты.xlsx` | «ВТБ-стиль»: `Дата`, `Документ №`, `Контрагент`, `Назначение`, `Сумма`, `Состояние` | нет колонки валюты вообще; внутри таблицы есть пустые строки и строка «Итого» (пропускаются) |
| `05_без_номеров_документов.xlsx` | выписка без номера платежа | сопоставление платежей **по реквизитам** (дата + сумма + контрагент + назначение), т.к. номера нет |
| `06_повторная_выгрузка_смена_статусов.xlsx` | повторная выгрузка того же счёта, что в №01 | часть статусов изменилась, добавились 2 новых платежа — дубликатов нет, а смена статусов видна в истории |

## Что должно получиться при импорте

| Файл | Строк | Создано | Обновлено | Пропущено строк |
|---|---|---|---|---|
| `01_классическая_выписка.xlsx` | 8 | 8 | 0 | 2 («Итого», «Остаток») |
| `02_статусы_латиницей.xlsx` | 7 | 7 | 0 | 0 |
| `03_состояние_документа.xlsx` | 6 | 6 | 0 | 0 |
| `04_сокращённая_без_валюты.xlsx` | 5 | 5 | 0 | 3 (2 пустые + «Итого») |
| `05_без_номеров_документов.xlsx` | 5 | 5 | 0 | 0 |
| `06_повторная_выгрузка_смена_статусов.xlsx` | 6 | 2 | 3 | 0 |

Файл №06 меняет статусы платежей из №01: `ПП-2002` в обработке → исполнен,
`ПП-2003` отклонён → отменён, `ПП-2007` отменён → исполнен; `ПП-2001` — без изменений.

## Как попробовать

Импортируйте **все** файлы, затем откройте **«Историю изменений»** по платежу `ПП-2002`:

```powershell
PaymentMonitor.exe --scan "fixtures\примеры"
PaymentMonitor.exe --list --limit 50
```

Чтобы увидеть смену статусов в истории, файл №06 должен импортироваться **после** №01 —
при обходе папки это происходит автоматически (порядок по имени).

## Как пересоздать

Нужен Python с `openpyxl`:

```powershell
pip install openpyxl
python fixtures\make_bank_examples.py
```
